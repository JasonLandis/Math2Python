# Math 2 Python

This is a website where I represent math subjects I find interesting using Python. The purpose is to show how these math subjects can be applied in code. Each lesson lists its source, and I highly recommend reading those directly, since my lessons aren't comprehensive. I will, however, include key points and definitions along with the code snippets. Thanks for stopping by!
